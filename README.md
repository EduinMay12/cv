# 💻 CV Web | Portafolio Profesional

### Desarrollador de Software | Backend & Fullstack

Currículum vitae digital desarrollado con tecnologías web, diseñado para presentar de manera profesional mi experiencia laboral, habilidades técnicas, formación académica, certificaciones y proyectos de desarrollo de software.

## 🚀 Sobre el proyecto

Este proyecto tiene como objetivo ofrecer una versión web de mi currículum profesional, permitiendo a reclutadores, empresas y profesionales del sector tecnológico conocer mi trayectoria, competencias y experiencia en desarrollo de aplicaciones.

## 👨‍💻 Sobre mí

Soy desarrollador de software con más de 5 años de experiencia en el desarrollo de aplicaciones web, especializado en Backend, APIs REST, automatización de procesos, integración de sistemas y arquitectura de microservicios.

He trabajado con tecnologías como PHP, Laravel, JavaScript, TypeScript, Node.js, C#, .NET, MySQL y servicios de AWS.

## 🛠️ Tecnologías

- **Frontend:** HTML5, CSS3, JavaScript, Bootstrap y Tailwind CSS.
- **Backend:** PHP, Laravel, Node.js, NestJS y .NET.
- **Bases de datos:** MySQL, SQL Server, MariaDB y MongoDB.
- **Cloud y DevOps:** AWS, Docker, Git y GitHub.
- **Arquitectura:** APIs REST, microservicios y autenticación JWT/OAuth.

## 🎯 Objetivo

Presentar mi perfil profesional mediante una experiencia web accesible, moderna y organizada, destacando mis competencias técnicas y experiencia en la construcción de soluciones de software.
